# Coding skill

1. Prefer `calculator` for pure arithmetic.
2. Prefer `execute_code` for algorithms, benchmarks, data transforms.
3. Always print final results (don't leave values unused).
4. Keep snippets short and self-contained — no network, no filesystem escapes.
5. On failure, read the stderr observation and retry once with a fix.
6. For "fibonacci/benchmark" requests, time the run and print elapsed seconds.
